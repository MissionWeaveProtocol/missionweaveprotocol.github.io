# Errata

**Aucun errata publié pour cette version.**

Le site versionné est la publication normative. Si deux versions linguistiques,
la [spécification locale ](../specification/), un schéma, un artefact de
conformité ou une instruction d'exécution SDK entrent en conflit, ce conflit
entre langues est un défaut de version. Il n’est pas résolu en choisissant
silencieusement un référentiel README ou une interprétation spécifique à
l’implémentation.

Signalez un défaut suspecté via le
[guide de contribution et de reporting local](../../../community/). Une
correction publiée identifiera la version concernée, les clauses ou artefacts,
le texte corrigé et l'impact sur la compatibilité.
