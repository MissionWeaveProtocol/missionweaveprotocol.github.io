# Spécification MissionWeaveProtocol 0.1

Ce site Web publie le **Projet de norme 0.1.0** sous la forme d'une version
normative unifiée. La prose versionnée, les schémas, les artefacts de
conformité, la broche de protocole et six broches SDK sont publiés ensemble.

L'interprétation des termes d'exigence en majuscules est définie par
[MWP-FND-001](./foundations/#mwp-fnd-001) sous BCP 14. Les identifiants de
clause restent des références stables dans cette version.
