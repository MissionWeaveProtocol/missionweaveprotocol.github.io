# Références d'exécution officielles SDK

:::caution[Draft Standard 0.1]

Ces pages SDK versionnées font partie de la publication normative du site Web.
Ils définissent la surface d'exécution publique prise en charge à chaque
validation SDK exacte. Les liens sources exacts établissent la provenance ; Les
pages README ou `docs/` du référentiel ne fournissent pas les exigences
manquantes.

:::

La [référence d'exécution ](../runtime/architecture-and-bootstrap/) partagée
définit l'ordre indépendant de la langue et les limites de confiance. Chaque
arborescence SDK ajoute sa véritable identité de package, sa chaîne d'outils,
ses noms publics, ses adaptateurs, ses exemples exécutables et ses limites de
disponibilité explicites sans fabriquer de parité entre les langues.

## Matrice de version exacte

<SdkRuntimeMatrix />

`Implemented` signifie que la source épinglée contient la surface publique
documentée. `Deployment adapter required` signifie que SDK fournit le contrat
d'exécution mais que le déploiement doit fournir une autorité externe, une
persistance ou une infrastructure réseau. `Not implemented` signifie que le SDK
épinglé n’a pas de surface d’exécution publique correspondante.
