# Rust SDK

`missionweaveprotocol` est le crate officiel Rust. Cette référence décrit le
commit exact `2727f8777737265d98dde4ceaca306612ef54c52`, la version du crate
`0.1.0`, Rust 1.85 ou plus récente et l'édition 2024. La pin documentée n'est
pas publiée sur crates.io ; une révision Git ou une archive de package
différente est une entrée d’implémentation différente.

:::note[Implementation note]

  <p slot="notes">
    Les applications lient la bibliothèque avec une dépendance Cargo Git dont{" "}
    <code>rev</code> est le commit exact ci-dessus. Une copie vendue ou emballée
    n'est acceptable que lorsque sa provenance se résout dans les mêmes octets
    et que ses ensembles de protocoles intégrés réussissent les appels de

Le binaire `missionweaveprotocol-conformance` accepte `--verbose` en option. Il
exécute les vecteurs de schéma structurels intégrés ; il n'établit pas la devise
Registry, la durabilité Admission Log, la sécurité du réseau ou la préparation à
la production.
