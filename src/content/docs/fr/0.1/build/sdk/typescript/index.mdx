# TypeScript SDK

`@missionweaveprotocol/sdk` est le package d'implémentation officiel de
TypeScript. Cette référence décrit le commit exact
`6d53ebfcf8350ae81d89fd818611b07f7373685c`, la version du package `0.1.0` et
Node.js 20 ou version ultérieure. Une construction de commit ou de package
différente est une entrée d'implémentation documentée différente, même lorsque
sa chaîne de version est inchangée.

:::note[Implementation note]

<SdkInstall
  sdk="typescript"
  command={`git clone https://github.com/MissionWeaveProtocol/typescript-sdk.git missionweaveprotocol-typescript-sdk
cd missionweaveprotocol-typescript-sdk
git checkout --detach 6d53ebfcf8350ae81d89fd818611b07f7373685c
npm ci
npm run build
npm pack --pack-destination ..
cd ..
npm install ./missionweaveprotocol-sdk-0.1.0.tgz`}
  verifyCommand={`node -e 'import("@missionweaveprotocol/sdk").then(({ sdkMetadata }) => console.log(sdkMetadata()))' npx --no-install missionweaveprotocol-conformance --json`}
>
  <p slot="notes">

    liée exactement au même commit.

:::

La commande `missionweaveprotocol-conformance` installée exécute le schéma et
les surfaces vectorielles packagés. Il n'établit pas l'autorité de déploiement,
la durabilité Admission Log, la sécurité du réseau ou la préparation à la
production.
