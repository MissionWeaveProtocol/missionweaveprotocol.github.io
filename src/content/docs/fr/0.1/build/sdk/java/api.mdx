# Java inventaire public API

Cet inventaire avec validation exacte est généré à partir de chaque source Java
sous `src/main/java/org/missionweaveprotocol/sdk` à
`3b2798c21d906c81887c54fe80e5bca8a19ddac7`. Il contient 298 classes publiques,
interfaces, types imbriqués, enregistrements et composants, énumérations et
membres, constantes, constructeurs, champs et méthodes déclarés par la source.
Les assistants privés de package et les déclarations de test/exemple sont
exclus.

L'inventaire est la référence de dénomination et de provenance exacte de la
source, et ne remplace pas la [sémantique d'exécution](../runtime/) ou le
[flux d'appel d'admission](../admission/).
