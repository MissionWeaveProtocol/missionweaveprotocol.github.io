# Allez SDK

`github.com/missionweaveprotocol/go-sdk` est le module d'implémentation officiel
de Go. Cette référence décrit la validation exacte
`80c39852e8a2053ac761b8d53d62483264f803f1` et Go 1.24. Une construction de
commit ou de module différente est une entrée d'implémentation documentée
différente.

:::note[Implementation note]

<SdkInstall
  sdk="go"
  command={`go get github.com/missionweaveprotocol/go-sdk@80c39852e8a2053ac761b8d53d62483264f803f1`}
  verifyCommand={`go list -m -f '{{.Path}} {{.Version}}' github.com/missionweaveprotocol/go-sdk
go run github.com/missionweaveprotocol/go-sdk/cmd/missionweaveprotocol-conformance@80c39852e8a2053ac761b8d53d62483264f803f1 -h`}
>
  <p slot="notes">
    Go résout la validation vers une version de module tout en conservant
    l'identité source documentée. Un proxy ou une copie vendue n'est acceptable
    que lorsque ses octets et sa provenance correspondent à la validation exacte
    et que ses ensembles de protocoles packagés passent les mêmes vérifications
    de résumé.
  </p>
</SdkInstall>

:::

La commande `missionweaveprotocol-conformance` exécute les surfaces schématiques
et vectorielles packagées prises en charge. Il n'établit pas l'autorité de
déploiement, la durabilité Admission Log, la sécurité du réseau ou la
préparation à la production.
