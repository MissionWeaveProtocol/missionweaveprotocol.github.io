# Java SDK

`org.missionweaveprotocol:missionweaveprotocol-sdk`
是官方 Java 工件。此參考描述了精確提交
`3b2798c21d906c81887c54fe80e5bca8a19ddac7`、版本 `0.1.0-SNAPSHOT`、Java
21 和 Maven
3.9。該工件是從確切的原始碼固定提交安裝的；不同的提交或本地安裝的快照是不同的實現輸入。

:::note[Implementation note]

<SdkInstall
  sdk="java"
  command={`git clone https://github.com/MissionWeaveProtocol/java-sdk.git missionweaveprotocol-java-sdk
cd missionweaveprotocol-java-sdk
git checkout --detach 3b2798c21d906c81887c54fe80e5bca8a19ddac7
./mvnw -B -ntp verify
./mvnw -B -ntp install`}
  verifyCommand={`./mvnw -q -Dexec.mainClass=org.missionweaveprotocol.sdk.cli.ConformanceCli -Dexec.args='' exec:java`}
>
  <p slot="notes">
    Maven 包裝器提供 Maven 3.9.x，但仍需要 Java 21
    運行時。下游建置必須將已安裝的工件固定到上面的確切提交的來源； SNAPSHOT
    版本字串本身並不能識別來源位元組。
  </p>
</SdkInstall>

:::

CLI 主類別是
`org.missionweaveprotocol.sdk.cli.ConformanceCli`。其支援的呼叫是`missionweaveprotocol-conformance [--root PATH]`；它沒有定義
`--help` 或 `--json`。在沒有根的情況下，它運行打包的結構模式向量。
