# 建置 MissionWeaveProtocol 0.1 運行時

:::caution[Draft Standard 0.1]

此版本化建構路徑是規範網站出版品的一部分。它將本地參考條款組織成實施順序，而不重新定義它們。當摘要和連結子句不同時，連結子句是控制要求。

:::

本地規範使用的 BCP 14 要求語言在
[MWP-FND-001](../reference/specification/foundations/#mwp-fnd-001).共享路徑描述了每種語言實作都必須保留的語義。 SDK 特定頁面可以新增安裝指令、語言類型和公用 API 語法，但不得削弱或取代這些規則。

:::note[Implementation note]

## 建議的實作順序

1. 引導精確的發布、信任邊界、驗證器、儲存和運行時身份。
2. 保留協定JSON、識別碼、時間戳記、雜湊值和信封類型沒有宿主語言規範化。
3. 實作嚴格的解析、Schema驗證、規範、簽章、Registry支援的金鑰解析和六階段驗證管道。
4. 密碼驗證之上的第一層存取與歷史信任。
5. 將權威狀態與可重建投影分開，然後實施重播、冪等性、防護和副作用恢復。
6. 透過規範的 WebSocket 訊框對群組進行身份驗證和復用。
7. 暴露穩定的線路錯誤，同時保留受保護的診斷和有用的信息操作信號。
8. 驗證確切的發布工件，報告經過驗證的一致性子集，以及升級時無需默默更改線路語意。

本命令為實施指南。連結的參考條款定義了要求及其接受範圍。

:::
