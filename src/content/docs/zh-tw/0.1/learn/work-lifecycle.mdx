# 工作生命週期

MissionWeaveProtocol keeps conversational cooperation fluid while making
executable responsibility
explicit.一個 Message 可以提供上下文或請求工作，但介面不能將其呈現為可執行指令（[MWP-MSN-017](../../reference/specification/missions-groups-and-membership/#mwp-msn-017)）。

## 從討論到承諾

1. **Discuss.** Agents exchange completed Messages in a
   Group 或者 WorkItem 對話。
2. **提議。 ** 任何 Group 會員可以提交工作提案。沒有可執行檔 WorkItem 還存在。
3. **授權。 **
   目前 Coordinator, 一個 MissionOwner 緊急超越，或一個 Agent 具有有效範圍的委託授權創建 WorkItem。
4. **報價。 **
   授權參與者提供 WorkItem 給符合資格的 Worker 和記錄選擇依據。獨佔授權集和委託報價規則由[MWP-MSN-019](../../reference/specification/missions-groups-and-membership/#mwp-msn-019)。
5. **接受。 **
   Worker 執行准入控制。驗收開啟新的旅程所有權紀元並放置 WorkItem 在那 Worker的每Group 隊列。

接受是持久的調度承諾，而不是立即執行。 Worker 的准入檢查和所有權影響由
[MWP-WRK-005](../../reference/specification/work-scheduling-and-recovery/#mwp-wrk-005)
定義。

## 工作合約

每個 WorkItem 都帶有版本化的、機器可讀的工作合約。其所需的形狀由
[MWP-WRK-001](../../reference/specification/work-scheduling-and-recovery/#mwp-wrk-001)
標識，包括：

- 目標、可交付成果和驗收標準；
- 需要 Evidence 和輸入或依賴項引用；
- 允許的工具、資料、資源和操作；
- 所需的能力標識符和版本；
- 截止日期、請求的緊迫性和業務影響；
- 財務、代幣、工具呼叫、計算、掛鐘和副作用預算；
- 重試嘗試、退避、截止日期和成本政策；和
- 風險分類和任何執行前審批門。

在接受之前解決了本質上的歧義。透過更新的 Worker 接受（[MWP-WRK-002](../../reference/specification/work-scheduling-and-recovery/#mwp-wrk-002)）返回重大合約修訂。

## 共同的成功之路

```text
Work Proposal
    ↓ authorize
open WorkItem
    ↓ offer
offered
    ↓ Worker accepts
queued
    ↓ valid ownership, approval gates, and Execution Lease
active
    ↓ Worker submits Artifacts and Evidence
submitted
    ↓ Coordinator accepts the result
verified
```

活動工作可能會檢查點回到 `queued`，輸入具有持久檢查點的
`blocked`，失敗並顯示 Evidence，或取消。完整的轉換錶位於
[WorkItem 規格頁](../../reference/specification/work-scheduling-and-recovery/#workitem-transition-table)。

## 批准前的 Evidence

一個 Worker 索賠並不能充分證明完成情況。提交內容包括文物和 Evidence 映射到驗收標準。 Coordinator 審查檢查 Artifact 完整性、確定性測試、定性審核員 Evidence，以及依照
[MWP-WRK-025 所描述的順序記錄的驗收決定](../../reference/specification/work-scheduling-and-recovery/#mwp-wrk-025)。

驗證所需的 WorkItem 後， Coordinator 提交具體的 Mission 修訂和 Artifact 放。這 MissionOwner 最終標誌 Approval 或要求更改而不刪除先前提交的內容 ([MWP-MSN-008](../../reference/specification/missions-groups-and-membership/#mwp-msn-008)).
