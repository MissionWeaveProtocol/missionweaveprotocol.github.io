# 學習 MissionWeaveProtocol 0.1

:::caution[Draft Standard 0.1]

此版本化學習路徑是規範網站出版品的一部分。它按讀者順序解釋了模型，並將每條規則連結到本地參考規範中的穩定條款。

:::

MissionWeaveProtocol 協調一個受信任的 Organization 內的自治代理。它將會話與執行權限分開，保持每個 Mission 的狀態和憑證隔離，並記錄重播、恢復、Evidence 和人員責任所需的持久事實。這些邊界以
[MWP-FND-002](../reference/specification/foundations/#mwp-fnd-002) 和
[核心不變量](../reference/specification/foundations/#mwp-fnd-013) 開始。

## 簡短版本

1. 人類 MissionOwner 創造一個有界的 Mission，定義為 did，截止日期、預算和審批政策。
2. Mission 恰好接收一個主 Group、一個持久 Event 歷史記錄，和可替換的 Coordinator。
3. Group 成員交換持久訊息並可能提出工作，但 Message 從不自行建立可執行權限（[MWP-FND-014](../reference/specification/foundations/#mwp-fnd-014)）。
4. 授權參與者使用機器可讀的工作合約建立 WorkItem。
5. Worker 執行準入控制，將報價接受到其每個 Group 中隊列，並透過其自己的調度程序跨組進行調度。
6. 工作產生內容尋址的工件和映射到接受的 Evidence 標準。
7. Coordinator 驗證結果，之後 MissionOwner 核准確切的 Mission 修訂版和 Artifact 集。

## 協定邊界

MissionWeaveProtocol 沒有定義 Agent-到-Agent
RPC、跨組織聯合、實體點對點路由、分散式共識、模型提示或私有模型推理。一 Organization 供應身分、政策、授權、耐用 Group 秩序和人的責任。 Mission 內容保留 Group-預設範圍（[MWP-FND-019](../reference/specification/foundations/#mwp-fnd-019)），而可審計的決策和結果不需要揭露私人思想鏈（[MWP-FND-022](../reference/specification/foundations/#mwp-fnd-022)）。
