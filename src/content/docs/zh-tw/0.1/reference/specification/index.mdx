# MissionWeaveProtocol 0.1 規範

本網站將**標準草案 0.1.0**
作為一個統一的規範版本發布。版本化的散文、模式、一致性工件、協定引腳和六個 SDK 引腳一起發布。

大寫要求術語的解釋由 BCP 14 下的 [MWP-FND-001](./foundations/#mwp-fnd-001)
定義。條款標識符在此版本中保持穩定的引用。
