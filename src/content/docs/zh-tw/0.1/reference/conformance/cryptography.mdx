## 六個語意階段

每個簽名文檔評估都使用以下有序分類：

1.嚴格UTF-8 JSON解析；2.規範JSON
Schema驗證；3. 簽名信封及保護時間驗證；4. 簽章金鑰解析和有效性驗證；5. RFC
8785規範化和簽章哈希生成；和6. Ed25519 簽章驗證。

相應的規範規則發佈在[簽名文檔和trust](../../specification/signed-documents-and-trust/)頁面中。
`complete` 表示該評估的所有六個階段均已完成。

透過此捆綁包並不能證明 First-Admission
Record 驗證、歷史信任驗證、Command 新鮮度或時鐘偏差強制執行，或適用角色和策略下的簽署者授權。
