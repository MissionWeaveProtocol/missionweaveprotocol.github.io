# 一致性曲面

MissionWeaveProtocol 0.1 將一致性證據分為三個獨立版本化的表面：

1. [結構一致性](./structural/)
   檢查 JSON 的架構有效性實施中立的文件。2.【密碼學一致性](./cryptography/)檢查了6個Signed
   Document驗證階段。3.【首次入場及歷史信任](./admission/)檢查已驗證在成功的六階段結果之上，也創下了接受記錄的行為。

通過一個表面並不意味著通過其他任何一個表面。完整的協議一致性也需要[本地規範](../specification/)中適用的行為條款的證據。
