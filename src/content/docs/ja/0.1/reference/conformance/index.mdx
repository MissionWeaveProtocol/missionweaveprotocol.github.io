# 適合面

MissionWeaveProtocol
0.1 は、適合証拠を 3 つの独立してバージョン管理されたサーフェスに分割します。

1. [構造適合性](./structural/)は、JSONスキーマの有効性をチェックします。実装に依存しないドキュメント。
2. [暗号化適合性](./cryptography/)は6つのSigned
   Documentをチェックします。検証段階。
3. [最初の入場と歴史的信頼](./admission/)
   チェックが認証されました成功した 6 段階の結果に基づく受け入れ記録の行動。

1 つのサーフェスを通過しても、他のサーフェスが通過することは意味しません。完全なプロトコル準拠には、[ローカル仕様](../specification/).
