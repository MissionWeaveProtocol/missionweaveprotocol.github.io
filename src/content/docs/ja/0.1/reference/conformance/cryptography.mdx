## 6 つのセマンティック ステージ

すべての署名付き文書の評価では、次の順序付けされた分類が使用されます。

1. 厳密な UTF-8 JSON 解析。
2. 標準的な JSON スキーマの検証。
3. 署名エンベロープと保護時間の検証。
4. 署名キーの解決と有効性の検証。
5. RFC 8785 正規化と署名ハッシュの生成。そして
6. Ed25519 署名の検証。

対応する規範ルールは、[署名された文書と trust](../../specification/signed-documents-and-trust/)
ページで公開されています。 `complete`
は、その評価の 6 つのステージすべてが完了したことを意味します。

このバンドルを渡すことは、First-Admission
Record 検証、履歴信頼検証、Command の鮮度またはクロック スキューの適用、または該当するロールとポリシーに基づく署名者の認可を証明するものではありません。
