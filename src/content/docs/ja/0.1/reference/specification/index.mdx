# MissionWeaveProtocol 0.1仕様

この Web サイトは、**ドラフト標準 0.1.0**
を 1 つの統一された標準リリースとして公開します。バージョン管理された散文、スキーマ、適合成果物、プロトコル ピン、および 6 つの SDK ピンが一緒にリリースされます。

大文字で始まる要件用語の解釈は、BCP 14 に基づく
[MWP-FND-001](./foundations/#mwp-fnd-001)
によって定義されています。条項識別子は、このリリース内でも安定した参照のままです。
