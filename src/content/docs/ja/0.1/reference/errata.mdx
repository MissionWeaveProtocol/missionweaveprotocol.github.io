# 正誤表

**このリリースには公開された正誤表はありません。**

バージョン管理された Web サイトが標準的な出版物です。 2 つの言語バージョン、ローカル仕様](../specification/)、スキーマ、適合成果物、または SDK ランタイム ステートメントが競合する場合、その言語間の競合はリリースの欠陥です。この問題は、リポジトリの README や実装固有の解釈を黙って選択しても解決されません。

欠陥の疑いがある場合は、[ローカル貢献および報告ガイド](../../../community/)] を通じて報告してください。公開された修正により、影響を受けるリリース、条項またはアーティファクト、修正されたテキスト、および互換性への影響が特定されます。
