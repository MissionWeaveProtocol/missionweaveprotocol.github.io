# アーティファクトとダイジェスト

ローカル プロトコル バンドルには、ツリー ダイジェスト

<code>{artifacts.bundle.digest}</code> を含む **{artifacts.bundle.files}
個の正確なファイル**が含まれています。プロトコル ピン SHA-256 は、

<code>{artifacts.protocolPin.sha256}</code> と固定プロトコル バンドル SHA-256 は
<code>{artifacts.protocolPin.bundleSha256}</code>。

| 表面           |                                                  ファイルまたはアーティファクト | ダイジェスト                                 |
| -------------- | ------------------------------------------------------------------------------: | -------------------------------------------- |
| スキーマ       |                                                       {artifacts.schemas.files} | <code>{artifacts.schemas.digest}</code>      |
| 構造適合性     | {artifacts.structural.files} ファイル / {artifacts.structural.vectors} ベクトル | <code>{artifacts.structural.digest}</code>   |
| 暗号化         |                                              {artifacts.cryptography.artifacts} | <code>{artifacts.cryptography.digest}</code> |
| アドミッション |                                                 {artifacts.admission.artifacts} | <code>{artifacts.admission.digest}</code>    |

## ダイジェスト セマンティクス

個々のマニフェスト エントリは、正確なファイル バイトを小文字の SHA-256 にバインドします。暗号化とアドミッションのトップレベル
`artifactDigest` 値は、そのメンバーを正確に削除し、残りのマニフェストを RFC 8785
JCS でシリアル化し、正規バイトをハッシュします。宣言されたアーティファクト エントリは、すべての名前付きファイルを推移的にバインドします。

Web サイトのバンドル ツリー ダイジェストは、各正規相対パス、NUL セパレータ、正確なファイル バイト、および末尾の NUL セパレータを、ソートされたパス順序でさらにバインドします。これにより、2 つの異なるアーティファクト レイアウトが、単に連結されたバイトが一致するという理由だけで ID を共有することがなくなります。
