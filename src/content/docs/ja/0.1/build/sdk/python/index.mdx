# Python SDK

`missionweaveprotocol`
パッケージは、Python リファレンス ランタイムです。このページでは、コミット
`9403cf1310914670506c56cbab363fdaa465d3cc`、パッケージ バージョン
`0.1.0`、および Python
3.12 以降について説明します。バージョン文字列が変更されていない場合でも、異なるコミットまたはパッケージのビルドは、文書化された異なる実装入力となります。

パッケージは、文書化されたコミットで次のコンソール コマンドを宣言します。

| Command                            | 公共目的                                                          |
| ---------------------------------- | ----------------------------------------------------------------- |
| `missionweaveprotocol-server`      | 構成された Group ゲートウェイ サービスを開始します。              |
| `missionweaveprotocol-demo`        | 決定論的なリファレンス ランタイムのデモを実行します。             |
| `missionweaveprotocol-conformance` | 実装に依存しない構造スキーマとベクトル マニフェストを実行します。 |

コマンドを開始しても、デプロイメント権限は作成されません。サーバーには、デプロイメント所有の Registry マテリアル、永続性、セッション資格情報、ネットワーク バインディング、および運用 TLS 構成が引き続き必要です。
