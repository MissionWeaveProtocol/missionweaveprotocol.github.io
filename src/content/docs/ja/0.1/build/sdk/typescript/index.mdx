# TypeScript SDK

`@missionweaveprotocol/sdk`
は、公式の TypeScript 実装パッケージです。このリファレンスでは、正確なコミット
`6d53ebfcf8350ae81d89fd818611b07f7373685c`、パッケージ バージョン
`0.1.0`、および Node.js
20 以降について説明します。バージョン文字列が変更されていない場合でも、異なるコミットまたはパッケージのビルドは、文書化された異なる実装入力となります。

:::note[Implementation note]

<SdkInstall
  sdk="typescript"
  command={`git clone https://github.com/MissionWeaveProtocol/typescript-sdk.git missionweaveprotocol-typescript-sdk

npm ci
npm run build
npm pack --pack-destination ..
cd ..
npm install ./missionweaveprotocol-sdk-0.1.0.tgz`}
  verifyCommand={`node -e 'import("@missionweaveprotocol/sdk").then(({ sdkMetadata }) => console.log(sdkMetadata()))' npx --no-install Missionweaveprotocol-conformance --json`}
>
  <p slot="notes">
    パッケージ ルートは、ESM ビルドと CommonJS
    ビルドの両方を提供します。パッケージ ルートと <code>package.json</code>{" "}
    のみがサポートされているエクスポートです。内部ソース ファイル
    パスはパブリック サブパス API ではありません。固定されたソース
    パッケージは、Git 依存関係の直接インストール中に <code>dist/</code>{" "}
    をビルドしないため、文書化されたフローでは tarball
    を明示的にビルドしてインストールします。別の tarball
    は、その来歴がまったく同じコミットにバインドされている場合にのみ、それを置き換えることができます。
  </p>
</SdkInstall>

:::

インストールされた `missionweaveprotocol-conformance`
コマンドは、パッケージ化されたスキーマおよびベクター サーフェスを実行します。デプロイメント権限、Admission
Log 耐久性、ネットワーク セキュリティ、実稼働の準備状態は確立されません。
