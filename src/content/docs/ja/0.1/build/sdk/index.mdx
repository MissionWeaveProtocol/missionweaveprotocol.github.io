# 公式 SDK ランタイム リファレンス

:::caution[Draft Standard 0.1]

これらのバージョン管理された SDK ページは、規範的な Web サイト公開物の一部です。各ページは、対応する正確な SDK コミットでサポートされる公開ランタイム面を定義します。正確なソースリンクは来歴を示しますが、リポジトリの README または
`docs/` ページでは、不足している要件が提供されていません。

:::

共有された [ランタイム参照](../runtime/architecture-and-bootstrap/)
は、言語に依存しない順序と信頼境界を定義します。各 SDK ツリーは、言語間のパリティを製造することなく、実際のパッケージ ID、ツールチェーン、パブリック名、アダプター、実行可能なサンプル、および明示的な可用性境界を追加します。

## 正確なリリース マトリックス

<SdkRuntimeMatrix />

`Implemented`
は、固定されたソースに文書化されたパブリック サーフェスが含まれていることを意味します。
`Deployment adapter required`
は、SDK がランタイム コントラクトを提供しますが、デプロイメントでは外部権限、永続性、またはネットワーク インフラストラクチャを提供する必要があることを意味します。
`Not implemented`
は、固定された SDK に対応するパブリック ランタイム サーフェスがないことを意味します。
