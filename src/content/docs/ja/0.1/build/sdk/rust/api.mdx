# Rust 公開 API インベントリ

この正確なコミット インベントリは、`src/lib.rs`
と、`2727f8777737265d98dde4ceaca306612ef54c52`
で選択的に再エクスポートされるモジュールから生成されます。これには、クレート ルートからアクセス可能な 311 個のパブリック構造体、列挙型とバリアント、トレイト、エイリアス、関数、定数、パブリック フィールド、およびパブリック メソッドが含まれています。クレート ルートによって再エクスポートされないプライベート モジュール パスと宣言は、アプリケーション コントラクトではありません。

インベントリは、名前付けと正確なソースの出所参照であり、ローカルの
[ランタイム セマンティクス](../runtime/) または
[入場コール フロー](../admission/) の代替ではありません。
