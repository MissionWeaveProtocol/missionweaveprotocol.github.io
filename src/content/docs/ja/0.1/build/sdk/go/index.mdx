# SDK に行く

`github.com/missionweaveprotocol/go-sdk`
は、公式の Go 実装モジュールです。このリファレンスでは、`80c39852e8a2053ac761b8d53d62483264f803f1`
と Go
1.24 の正確なコミットについて説明します。別のコミットまたはモジュールのビルドは、文書化された別の実装入力です。

:::note[Implementation note]

<SdkInstall
  sdk="go"
  command={`go get github.com/missionweaveprotocol/go-sdk@80c39852e8a2053ac761b8d53d62483264f803f1`}
  verifyCommand={`go list -m -f '{{.Path}} {{.Version}}' github.com/missionweaveprotocol/go-sdk
go run github.com/missionweaveprotocol/go-sdk/cmd/missionweaveprotocol-conformance@80c39852e8a2053ac761b8d53d62483264f803f1 -h`}
>
  <p slot="notes">
    Go は、文書化されたソース ID を保持しながら、モジュール
    バージョンへのコミットを解決します。プロキシまたはベンダーのコピーは、そのバイトと来歴が正確なコミットに対応し、パッケージ化されたプロトコル
    バンドルが同じダイジェスト チェックに合格する場合にのみ受け入れられます。
  </p>
</SdkInstall>

:::

`missionweaveprotocol-conformance`
コマンドは、サポートされているパッケージ化されたスキーマおよびベクター サーフェスを実行します。デプロイメント権限、Admission
Log 耐久性、ネットワーク セキュリティ、実稼働の準備状態は確立されません。
