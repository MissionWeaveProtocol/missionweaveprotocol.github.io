# Go 公開 API インベントリ

にあるルート パッケージ ソース ファイルから生成されます。そのコミット時に存在する宣言を使用して、エクスポートされた型、インターフェイス、構造体、定数、関数、メソッド、およびアクセサーを記録します。

の代替ではありません。宣言の存在は、その契約が要求する外部権限、原子性、耐久性、または認証された証拠を提供するものではありません。
