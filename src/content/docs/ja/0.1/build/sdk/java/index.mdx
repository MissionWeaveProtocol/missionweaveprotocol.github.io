# Java SDK

`org.missionweaveprotocol:missionweaveprotocol-sdk`
は、公式の Java アーティファクトです。このリファレンスでは、正確なコミット
`3b2798c21d906c81887c54fe80e5bca8a19ddac7`、バージョン `0.1.0-SNAPSHOT`、Java
21、および Maven
3.9 について説明します。アーティファクトは正確なソース ピンからインストールされます。別のコミットまたはローカルにインストールされた SNAPSHOT は別の実装入力です。

:::note[Implementation note]

<SdkInstall
  sdk="java"
  command={`git clone https://github.com/MissionWeaveProtocol/java-sdk.git missionweaveprotocol-java-sdk
cd missionweaveprotocol-java-sdk
git checkout --detach 3b2798c21d906c81887c54fe80e5bca8a19ddac7
./mvnw -B -ntp verify
./mvnw -B -ntp install`}
  verifyCommand={`./mvnw -q -Dexec.mainClass=org.missionweaveprotocol.sdk.cli.ConformanceCli -Dexec.args='' exec:java`}
>
  <p slot="notes">
    Maven ラッパーは Maven 3.9.x を提供しますが、依然として Java 21
    ランタイムが必要です。ダウンストリーム
    ビルドでは、上記の正確なコミットのために、インストールされたアーティファクトの出自を固定する必要があります。
    SNAPSHOT バージョン文字列だけではソース バイトを識別しません。
  </p>
</SdkInstall>

:::

CLI のメイン クラスは `org.missionweaveprotocol.sdk.cli.ConformanceCli`
です。サポートされている呼び出しは
`missionweaveprotocol-conformance [--root PATH]` です。 `--help` または `--json`
は定義されていません。ルートがない場合は、パッケージ化された構造スキーマ ベクトルを実行します。
