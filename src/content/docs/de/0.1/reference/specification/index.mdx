# MissionWeaveProtocol 0.1 Spezifikation

Diese Website veröffentlicht **Draft Standard 0.1.0** als eine einheitliche
normative Version. Die versionierte Prosa, Schemata, Konformitätsartefakte, der
Protokoll-Pin und sechs SDK-Pins werden zusammen veröffentlicht.

Die Interpretation großgeschriebener Anforderungsbegriffe wird durch
[MWP-FND-001](./foundations/#mwp-fnd-001) unter BCP 14 definiert.
Klauselbezeichner bleiben in dieser Version stabile Referenzen.
