# Errata

**Keine veröffentlichten Errata für diese Version.**

Die versionierte Website ist die normative Veröffentlichung. Wenn zwei
Sprachversionen, die [lokale Spezifikation](../specification/), ein Schema, ein
Konformitätsartefakt oder eine SDK-Laufzeitanweisung, in Konflikt stehen,
handelt es sich bei diesem sprachübergreifenden Konflikt um einen Releasefehler.
Es lässt sich nicht dadurch lösen, dass man stillschweigend eine
Repository-README-Datei oder eine umsetzungsspezifische Interpretation auswählt.

Melden Sie einen vermuteten Defekt über den
[lokalen Beitrags- und Meldeleitfaden](../../../community/). Eine
veröffentlichte Korrektur identifiziert die betroffene Version, Klauseln oder
Artefakte, den korrigierten Text und die Auswirkungen auf die Kompatibilität.
