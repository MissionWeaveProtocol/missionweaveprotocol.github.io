# Java SDK

`org.missionweaveprotocol:missionweaveprotocol-sdk` ist das offizielle
Java-Artefakt. Diese Referenz beschreibt den genauen Commit
`3b2798c21d906c81887c54fe80e5bca8a19ddac7`, Version `0.1.0-SNAPSHOT`, Java 21
und Maven 3.9. Das Artefakt wird vom exakten Quell-Pin aus installiert; Ein
anderes Commit oder ein lokal installierter SNAPSHOT ist eine andere
Implementierungseingabe.

:::note[Implementation note]

<SdkInstall
  sdk="java"
  command={`git clone https://github.com/MissionWeaveProtocol/java-sdk.git missionweaveprotocol-java-sdk
cd missionweaveprotocol-java-sdk
git checkout --detach 3b2798c21d906c81887c54fe80e5bca8a19ddac7
./mvnw -B -ntp verify
./mvnw -B -ntp install`}
  verifyCommand={`./mvnw -q -Dexec.mainClass=org.missionweaveprotocol.sdk.cli.ConformanceCli -Dexec.args='' exec:java`}
>
  <p slot="notes">
    Der Maven-Wrapper stellt Maven 3.9.x bereit, erfordert jedoch weiterhin eine
    Java 21-Laufzeit. Downstream-Builds müssen das installierte Artefakt für den
    genauen oben genannten Commit an die Herkunft anheften; Die
    SNAPSHOT-Versionszeichenfolge allein identifiziert keine Quellbytes.
  </p>
</SdkInstall>

:::

Die CLI-Hauptklasse ist `org.missionweaveprotocol.sdk.cli.ConformanceCli`. Der
unterstützte Aufruf ist `missionweaveprotocol-conformance [--root PATH]`; Es
definiert weder `--help` noch `--json`. Ohne Root werden gepackte strukturelle
Schema-Vektoren ausgeführt.
