# Gehen Sie zu SDK

`github.com/missionweaveprotocol/go-sdk` ist das offizielle
Go-Implementierungsmodul. Diese Referenz beschreibt den genauen Commit
`80c39852e8a2053ac761b8d53d62483264f803f1` und Go 1.24. Ein anderer Commit oder
Modul-Build ist eine andere dokumentierte Implementierungseingabe.

:::note[Implementation note]

<SdkInstall
  sdk="go"
  command={`go get github.com/missionweaveprotocol/go-sdk@80c39852e8a2053ac761b8d53d62483264f803f1`}
  verifyCommand={`go list -m -f '{{.Path}} {{.Version}}' github.com/missionweaveprotocol/go-sdk
go run github.com/missionweaveprotocol/go-sdk/cmd/missionweaveprotocol-conformance@80c39852e8a2053ac761b8d53d62483264f803f1 -h`}
>
  <p slot="notes">
    Go löst den Commit auf eine Modulversion auf und behält dabei die
    dokumentierte Quellidentität bei. Ein Proxy oder eine verkaufte Kopie ist
    nur akzeptabel, wenn seine Bytes und Herkunft mit dem exakten Commit
    übereinstimmen und seine gepackten Protokollpakete dieselben
    Digest-Prüfungen bestehen.
  </p>
</SdkInstall>

:::

Der Befehl `missionweaveprotocol-conformance` führt das unterstützte Paketschema
und die Vektoroberflächen aus. Es stellt keine Bereitstellungsautorität,
Admission Log Haltbarkeit, Netzwerksicherheit oder Produktionsbereitschaft her.
