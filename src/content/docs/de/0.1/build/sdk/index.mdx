# Offizielle SDK Laufzeitreferenzen

:::caution[Draft Standard 0.1]

Diese versionierten SDK-Seiten sind Teil der normativen
Website-Veröffentlichung. Sie definieren die unterstützte öffentliche
Laufzeitoberfläche bei jedem genauen SDK-Commit. Genaue Quellenlinks legen die
Herkunft fest; Die Repository-README- oder `docs/`-Seiten enthalten keine
fehlenden Anforderungen.

:::

Die gemeinsame [Laufzeitreferenz](../runtime/architecture-and-bootstrap/)
definiert die sprachunabhängige Reihenfolge und Vertrauensgrenzen. Jeder
SDK-Baum fügt seine echte Paketidentität, Toolchain, öffentliche Namen, Adapter,
ausführbare Beispiele und explizite Verfügbarkeitsgrenzen hinzu, ohne
sprachübergreifende Parität herzustellen.

## Genaue Release-Matrix

<SdkRuntimeMatrix />

`Implemented` bedeutet, dass die angeheftete Quelle die dokumentierte
öffentliche Oberfläche enthält. `Deployment adapter required` bedeutet, dass SDK
den Laufzeitvertrag bereitstellt, die Bereitstellung jedoch externe Autorität,
Persistenz oder Netzwerkinfrastruktur bereitstellen muss. `Not implemented`
bedeutet, dass der angeheftete SDK keine entsprechende öffentliche
Laufzeitoberfläche hat.
