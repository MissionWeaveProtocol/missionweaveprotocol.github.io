# 官方 SDK 运行时参考

:::caution[Draft Standard 0.1]

这些版本化的 SDK 页面是规范网站出版物的一部分。它们在每个确切的 SDK 提交时定义受支持的公共运行时表面。准确的来源链接可确定出处；存储库 README 或
`docs/` 页面不提供缺失的要求。

:::

共享的[运行时参考](../runtime/architecture-and-bootstrap/)定义了与语言无关的顺序和信任边界。每个 SDK 树都添加其真实的包标识、工具链、公共名称、适配器、可运行示例和显式可用性边界，而无需制造跨语言奇偶校验。

## 精确的释放矩阵

<SdkRuntimeMatrix />

`Implemented` 表示固定源包含记录的公共表面。 `Deployment adapter required`
表示 SDK 提供运行时合约，但部署必须提供外部权限、持久性或网络基础设施。
`Not implemented` 表示固定的 SDK 没有相应的公共运行时表面。
