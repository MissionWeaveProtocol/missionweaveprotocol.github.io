# C++ 运行时参考

此页面涵盖了由[确切的 API inventory](../api/)
表示的完整 C++ 表面。共享协议行为仍然由本地[运行时参考](../../../runtime/architecture-and-bootstrap/)和[参考子句](../../../../reference/specification/)定义。公共声明位于命名空间
`missionweaveprotocol` 中；下游 CMake 目标链接 `MissionWeaveProtocol::sdk`。

<SupportStatus status="implemented" /> 适用于下面列出的已安装标头和进程内行为。

<SupportStatus status="deployment-adapter-required" /> 适用于当前 Registry
权威性、可信准入上下文、经过身份验证的日志访问和其他部署服务。

<SupportStatus status="not-implemented" /> 表示精确固定的库没有相应的运行时。

## 库和执行模型

安装的包需要 C++20、CMake 3.24、OpenSSL 3 和 jsoncons
1.8.1。其导出目标为`MissionWeaveProtocol::sdk`；安装的公共标头位于
`include/missionweaveprotocol` 下。单独安装的可执行文件是
`missionweaveprotocol-conformance`。

链接库不会启动任何服务，不会打开套接字，不会创建持久存储，并且不会授予任何权限。
`std::span`
结果根据声明 API 引用 SDK 拥有的或对象拥有的字节，并且不得比其所有者寿命更长。

## 验证、签名和 Registry 证据

`parse_strict_json` 只接受一个 JSON 值。 `SchemaCatalog::validate`
检查 22 个嵌入式草案 2020-12 架构。
`canonical_json`、`canonicalize_json`、`canonical_sha256` 和
`canonical_sha256_document` 实现 RFC 8785 表面。

`SigningKey` 是应用程序拥有的签名接口。 `Ed25519`
公开严格的密钥、签名和文档帮助程序。 `SignedDocumentCodec::sign` 和 `verify`
选择九个 `SignedDocumentKind`
值之一并运行解析、架构、签名信封、密钥解析、规范化和签名阶段。

`KeyResolver::resolve` 必须返回 `KeyRegistrySnapshot::organization_wide`
证据，以获取具有完整保留历史记录的一个连贯的适用 Organization 修订版。选定的密钥、部分投影、缓存命中或调用者提供的信任标志是不够的。
`VerifiedSignedDocument`
公开接收到的字节、签名和规范字符串和哈希值、受保护的时间、签名材料以及解析的 Registry 密钥和 Principal。

## 框架、捆绑包和一致性

`FrameCodec::decode`、`encode` 和 `validate_document`
验证帧值；它们不拥有传输、TLS、会话身份验证、游标持久性、路由、背压或权威状态转换。

`ProtocolBundle::verify` 检查 22 个架构和 59 个文件结构包。
`verify_cryptography` 检查 98 个工件、22 个案例和 62 个声明的评估；
`verify_admission`
检查 19 个工件、5 个案例和 30 个声明的评估。这些调用验证固定值、计数、路径、字节长度和摘要，但不执行每个加密或准入评估。

`ConformanceRunner::run` 和 `missionweaveprotocol-conformance`
仅执行嵌入的结构模式向量。仅当所有向量都符合其预期有效性时，可执行文件才返回零。

## 明确的可用性边界

<SupportStatus status="deployment-adapter-required" /> **准入权威服务** —
应用程序提供当前 Registry 证据、历史 Registry
证据、可信接受上下文以及经过身份验证的仅附加日志。

<SupportStatus status="not-implemented" /> **Mission 编排** — 不导出高级 Mission
状态机或编排外观。

<SupportStatus status="not-implemented" /> **Worker 调度程序** — 不导出 Worker
队列、调度程序、租用运行程序或恢复循环。

<SupportStatus status="not-implemented" /> **托管网关服务** — 库提供
`FrameCodec`，而不是具有传输、TLS、会话、路由或反压所有权的网关服务。

<SupportStatus status="not-implemented" /> **权威持久性运行时** —
不导出数据库支持或 Agent 本地持久性运行时。

这些未实现项是书面支持合同的一部分；不得从共享协议名称推断 Python 参考运行时能力。
