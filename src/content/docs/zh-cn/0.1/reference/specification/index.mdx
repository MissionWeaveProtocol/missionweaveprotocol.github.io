# MissionWeaveProtocol 0.1 规范

本网站将**标准草案 0.1.0**
作为一个统一的规范版本发布。版本化的散文、模式、一致性工件、协议引脚和六个 SDK 引脚一起发布。

大写要求术语的解释由 BCP 14 下的 [MWP-FND-001](./foundations/#mwp-fnd-001)
定义。条款标识符在此版本中保持稳定的引用。
