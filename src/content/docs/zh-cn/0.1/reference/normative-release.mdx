# 规范发布标识

MissionWeaveProtocol
0.1 作为一个网站、协议工件包和六个确切的 SDK 引脚发布。提交的
`release-source.json`
记录每个非自引用输入：协议和 SDK 提交、发布计数、配置文件身份、摘要、区域设置和内置树摘要算法。

公众

<ArtifactLink path="normative-release.json">
  <code>normative-release.json</code>
</ArtifactLink>
在生产构建期间生成。它复制每个提交的发布源字段并添加：

- `websiteCommit`，确切的网站 Git 提交；
- `buildIdentity`，GitHub 运行/尝试对或本地提交身份；和
- `contentDigests`，为每个语言环境构建的 HTML 树的一个摘要。

生成的清单未提交，因为已提交的文件无法真实包含包含其自身的提交的 Git 标识。发布验证会重建生成的字段，并将每个提交的字段与
`release-source.json` 进行比较。
