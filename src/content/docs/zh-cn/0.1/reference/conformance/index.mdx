# 一致性曲面

MissionWeaveProtocol 0.1 将一致性证据分为三个独立版本化的表面：

1. [结构一致性](./structural/)
   检查 JSON 的架构有效性实施中立的文件。2.【密码学一致性](./cryptography/)检查了6个Signed
   Document验证阶段。3.【首次入场及历史信任](./admission/)检查已验证在成功的六阶段结果之上，还创下了接受记录的行为。

通过一个表面并不意味着通过其他任何一个表面。完整的协议一致性还需要[本地规范](../specification/)中适用的行为条款的证据。
