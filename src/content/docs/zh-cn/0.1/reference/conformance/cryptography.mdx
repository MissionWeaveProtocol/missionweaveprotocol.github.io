## 六个语义阶段

每个签名文档评估都使用以下有序分类：

1. 严格解析 UTF-8 JSON；
2. 执行规范 JSON Schema 验证；
3. 验证签名信封和受保护时间；
4. 解析签名密钥并验证有效性；
5. 执行 RFC 8785 规范化并生成签名哈希；
6. 验证 Ed25519 签名。

相应的规范规则发布在[签名文档和trust](../../specification/signed-documents-and-trust/)页面中。
`complete` 表示该评估的所有六个阶段均已完成。

通过此捆绑包并不能证明 First-Admission
Record 验证、历史信任验证、Command 新鲜度或时钟偏差强制执行，或适用角色和策略下的签名者授权。
