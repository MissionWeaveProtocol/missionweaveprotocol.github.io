# MissionWeaveProtocol 0.1 especificación

Este sitio web publica el **Borrador de Estándar 0.1.0** como una versión
normativa unificada. La prosa versionada, los esquemas, los artefactos de
conformidad, el pin de protocolo y seis pines SDK se liberan juntos.

La interpretación de los términos de los requisitos capitalizados se define en
[MWP-FND-001](./foundations/#mwp-fnd-001) según BCP 14. Los identificadores de
cláusulas siguen siendo referencias estables en esta versión.
