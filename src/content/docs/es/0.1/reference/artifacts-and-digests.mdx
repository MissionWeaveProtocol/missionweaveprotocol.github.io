# Artefactos y resúmenes

El paquete de protocolo local contiene **{artifacts.bundle.files} archivos
exactos** con un resumen de árbol <code>{artifacts.bundle.digest}</code>. El pin
de protocolo SHA-256 es

<code>{artifacts.protocolPin.sha256}</code> y el paquete de protocolo anclado
SHA-256 es <code>{artifacts.protocolPin.bundleSha256}</code>.

| Superficie              |                                                           Archivos o artefactos | Resumen                                      |
| ----------------------- | ------------------------------------------------------------------------------: | -------------------------------------------- |
| Esquemas                |                                                  {artefactos.esquemas.archivos} | <code>{artifacts.schemas.digest}</code>      |
| Conformidad estructural | {artifacts.structural.files} archivos / {artifacts.structural.vectors} vectores | <code>{artifacts.structural.digest}</code>   |
| Criptografía            |                                            {artefactos.criptografía.artefactos} | <code>{artifacts.cryptography.digest}</code> |
| Admisión                |                                                {artefactos.admisión.artefactos} | <code>{artifacts.admission.digest}</code>    |

## Resumen de semántica

Las entradas del manifiesto individual vinculan bytes de archivo exactos con
SHA-256 en minúscula. Los valores `artifactDigest` de nivel superior de
criptografía y Admisión eliminan exactamente ese miembro, serializan el
manifiesto restante con RFC 8785 JCS y aplican hash a los bytes canónicos. Sus
entradas de artefactos declaradas vinculan transitivamente cada archivo
nombrado.

El resumen del árbol del paquete del sitio web vincula adicionalmente cada ruta
relativa canónica, un separador NUL, los bytes exactos del archivo y un
separador NUL final en orden de ruta ordenado. Esto evita que dos diseños de
artefactos diferentes compartan una identidad simplemente porque sus bytes
concatenados coinciden.
