# Fe de erratas

**No hay erratas publicadas para esta versión.**

El sitio web versionado es la publicación normativa. Si hay dos versiones de
idiomas, la [especificación local ](../specification/), un esquema, un artefacto
de conformidad o una declaración de tiempo de ejecución SDK entran en conflicto,
ese conflicto entre idiomas es un defecto de versión. No se resuelve eligiendo
silenciosamente un README del repositorio o una interpretación específica de la
implementación.

Informe un defecto sospechoso a través de la
[guía de informes y contribuciones locales](../../../community/). Una corrección
publicada identificará la versión afectada, las cláusulas o artefactos, el texto
corregido y el impacto en la compatibilidad.
