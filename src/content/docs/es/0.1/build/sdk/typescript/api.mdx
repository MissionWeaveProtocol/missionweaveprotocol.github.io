# TypeScript inventario público API

Este inventario de confirmación exacta se genera a partir de las declaraciones
de exportación de raíz de paquete real en
`6d53ebfcf8350ae81d89fd818611b07f7373685c`. Las exportaciones estrella incluyen
sus declaraciones públicas; Las exportaciones selectivas incluyen solo la
superficie de raíz nombrada. Se excluyen las importaciones ordinarias y las
declaraciones exclusivamente internas.

El inventario es la referencia de denominación y procedencia exacta de la
fuente, no un sustituto de la [semántica de tiempo de ejecución](../runtime/) o
[flujo de llamada de admisión](../admission/). El paquete exporta sólo `.` y
`./package.json`; Un módulo fuente enumerado aquí no es una subruta de paquete
compatible de forma independiente.
