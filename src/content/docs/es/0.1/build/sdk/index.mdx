# Referencias oficiales de tiempo de ejecución SDK

:::caution[Draft Standard 0.1]

Estas páginas SDK versionadas forman parte de la publicación normativa del sitio
web. Definen la superficie de tiempo de ejecución pública admitida en cada
confirmación SDK exacta. Los enlaces de fuentes exactas establecen la
procedencia; Las páginas README o `docs/` del repositorio no proporcionan los
requisitos faltantes.

:::

La [referencia de tiempo de ejecución](../runtime/architecture-and-bootstrap/)
compartida define el orden independiente del idioma y los límites de confianza.
Cada árbol SDK agrega su identidad de paquete real, cadena de herramientas,
nombres públicos, adaptadores, ejemplos ejecutables y límites de disponibilidad
explícitos sin crear paridad entre idiomas.

## Matriz de liberación exacta

<SdkRuntimeMatrix />

`Implemented` significa que la fuente fijada contiene la superficie pública
documentada. `Deployment adapter required` significa que SDK proporciona el
contrato de ejecución, pero la implementación debe proporcionar autoridad
externa, persistencia o infraestructura de red. `Not implemented` significa que
el SDK anclado no tiene una superficie de tiempo de ejecución pública
correspondiente.
