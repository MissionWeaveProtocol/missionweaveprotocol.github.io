# Python SDK

El paquete `missionweaveprotocol` es el tiempo de ejecución de referencia
Python. Esta página describe la confirmación
`9403cf1310914670506c56cbab363fdaa465d3cc`, la versión del paquete `0.1.0` y
Python 3.12 o posterior. Una confirmación o compilación de paquete diferente es
una entrada de implementación documentada diferente, incluso cuando su cadena de
versión no ha cambiado.

:::note[Implementation note]

<SdkInstall
  sdk="python"
  command={`uv add "missionweaveprotocol @ git+https://github.com/MissionWeaveProtocol/python-sdk.git@9403cf1310914670506c56cbab363fdaa465d3cc"`}
  verifyCommand={`uv run python -c "import missionweaveprotocol as mwp; print(mwp.__version__)"
uv run missionweaveprotocol-conformance --help`}
>
  <p slot="notes">
    El requisito exacto de VCS construye el paquete a partir de la confirmación
    documentada. En cambio, una implementación puede instalar una rueda cuyo
    origen de compilación esté vinculado a ese compromiso y cuyos artefactos
    empaquetados pasen las mismas comprobaciones de resumen.
  </p>
</SdkInstall>

:::

El paquete declara estos comandos de consola en la confirmación documentada:

| Command                            | Finalidad pública                                                                   |
| ---------------------------------- | ----------------------------------------------------------------------------------- |
| `missionweaveprotocol-server`      | Inicie el servicio de puerta de enlace Group configurado.                           |
| `missionweaveprotocol-demo`        | Ejecute la demostración determinista en tiempo de ejecución de referencia.          |
| `missionweaveprotocol-conformance` | Ejecute el esquema estructural y el manifiesto vectorial de implementación neutral. |

Iniciar un comando no crea autoridad de implementación. El servidor aún requiere
material Registry propiedad de la implementación, persistencia, credenciales de
sesión, enlace de red y configuración TLS de producción.
