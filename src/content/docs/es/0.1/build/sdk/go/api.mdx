Este inventario de confirmación exacta se genera a partir de los archivos fuente
del paquete raíz en `80c39852e8a2053ac761b8d53d62483264f803f1`. Registra los

fuente, no un sustituto de la [semántica de tiempo de ejecución](../runtime/) o

no proporciona la autoridad externa, la atomicidad, la durabilidad o la
evidencia autenticada que requiere su contrato.
