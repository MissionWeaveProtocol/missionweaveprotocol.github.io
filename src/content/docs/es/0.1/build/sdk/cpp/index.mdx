# C++ SDK

`MissionWeaveProtocol::sdk` es el destino CMake instalado para el C++ SDK
oficial. Esta referencia describe la confirmación exacta
`481b0ce3a65c1f2265935318b54481ece5032fdf`, versión `0.1.0`, C++20, CMake 3.24 o
posterior, OpenSSL 3 y jsoncons 1.8.1. Una revisión de fuente diferente o un
prefijo instalado es una entrada de implementación diferente.

:::note[Implementation note]

<SdkInstall
  sdk="cpp"
  command={`git clone https://github.com/MissionWeaveProtocol/cpp-sdk.git missionweaveprotocol-cpp-sdk
cd missionweaveprotocol-cpp-sdk
git checkout --detach 481b0ce3a65c1f2265935318b54481ece5032fdf
cmake -S . -B build -DMISSIONWEAVEPROTOCOL_BUILD_TESTS=ON -DMISSIONWEAVEPROTOCOL_BUILD_EXAMPLES=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
cmake --install build --prefix /absolute/install/prefix`}
  verifyCommand={`/absolute/install/prefix/bin/missionweaveprotocol-conformance`}
>
  <p slot="notes">
    Configure con <code>OPENSSL_ROOT_DIR</code> cuando CMake encuentre una
    implementación que no sea OpenSSL o anterior a 3.0. La compilación primero
    busca jsoncons 1.8.1 y, de lo contrario, descarga el archivo v1.8.1 exacto
    con un SHA-256 anclado. Los proyectos posteriores de CMake configuran{" "}
    <code>find_package(missionweaveprotocol CONFIG)</code>, fallan en su propia
    compilación cuando el paquete está ausente y vinculan{" "}
    <code>MissionWeaveProtocol::sdk</code>.
  </p>
</SdkInstall>

:::

El ejecutable `missionweaveprotocol-conformance` instalado ejecuta los vectores
de esquema estructural integrados. No acepta opciones documentadas y no
establece moneda Registry, durabilidad Admission Log, seguridad de red o
preparación para producción.
