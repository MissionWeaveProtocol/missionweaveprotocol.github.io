Schema Draft 2020-12 files. The files below are the exact local release
artifacts. Their shared validation notes are available in the

Schema validation is assertion-based, including every declared `format`. The
complete local rule is [MWP-FND-009](../specification/foundations/#mwp-fnd-009).
Passing these schemas proves structural shape only; it does not replace the
behavioral, cryptographic, or Admission requirements.
