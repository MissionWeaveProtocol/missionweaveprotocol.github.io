# Errata

**No published errata for this release.**

The versioned website is the normative publication. If two language versions,
the [local specification](../specification/), a schema, a conformance artifact,
or an SDK runtime statement conflict, that cross-language conflict is a release
defect. It is not resolved by silently choosing a repository README or an
implementation-specific interpretation.

Report a suspected defect through the
[local contribution and reporting guide](../../../community/). A published
correction will identify the affected release, clauses or artifacts, corrected
text, and compatibility impact.
