# Go SDK

`github.com/missionweaveprotocol/go-sdk` is the official Go implementation
module. This reference describes exact commit
`80c39852e8a2053ac761b8d53d62483264f803f1` and Go 1.24. A different commit or
module build is a different documented implementation input.

:::note[Implementation note]

<SdkInstall
  sdk="go"
  command={`go get github.com/missionweaveprotocol/go-sdk@80c39852e8a2053ac761b8d53d62483264f803f1`}
  verifyCommand={`go list -m -f '{{.Path}} {{.Version}}' github.com/missionweaveprotocol/go-sdk
go run github.com/missionweaveprotocol/go-sdk/cmd/missionweaveprotocol-conformance@80c39852e8a2053ac761b8d53d62483264f803f1 -h`}
>
  <p slot="notes">
    Go resolves the commit to a module version while retaining the documented
    source identity. A proxy or vendored copy is acceptable only when its bytes
    and provenance correspond to the exact commit and its packaged protocol
    bundles pass the same digest checks.
  </p>
</SdkInstall>

:::

The `missionweaveprotocol-conformance` command runs the supported packaged
Schema and vector surfaces. It does not establish deployment authority,
Admission Log durability, network security, or production readiness.
