# Java SDK

`org.missionweaveprotocol:missionweaveprotocol-sdk` is the official Java
artifact. This reference describes exact commit
`3b2798c21d906c81887c54fe80e5bca8a19ddac7`, version `0.1.0-SNAPSHOT`, Java 21,
and Maven 3.9. The artifact is installed from the exact source pin; a different
commit or locally installed SNAPSHOT is a different implementation input.

:::note[Implementation note]

<SdkInstall
  sdk="java"
  command={`git clone https://github.com/MissionWeaveProtocol/java-sdk.git missionweaveprotocol-java-sdk
cd missionweaveprotocol-java-sdk
git checkout --detach 3b2798c21d906c81887c54fe80e5bca8a19ddac7
./mvnw -B -ntp verify
./mvnw -B -ntp install`}
  verifyCommand={`./mvnw -q -Dexec.mainClass=org.missionweaveprotocol.sdk.cli.ConformanceCli -Dexec.args='' exec:java`}
>
  <p slot="notes">
    The Maven wrapper supplies Maven 3.9.x but still requires a Java 21 runtime.
    Downstream builds must pin the installed artifact to provenance for the
    exact commit above; the SNAPSHOT version string alone does not identify
    source bytes.
  </p>
</SdkInstall>

:::

The CLI main class is `org.missionweaveprotocol.sdk.cli.ConformanceCli`. Its
supported invocation is `missionweaveprotocol-conformance [--root PATH]`; it
does not define `--help` or `--json`. With no root it runs packaged structural
Schema vectors.
